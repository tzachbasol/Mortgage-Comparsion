# תיבת צילומים לעיבוד

שימו כאן צילומי מסך של הצעות משכנתא (מפייסבוק, פורומים, וואטסאפ).
עבור כל צילום כדאי להוסיף קובץ טקסט באותו שם (`xxx.txt`) עם:

```
קבוצה: <שם הקבוצה>
קישור: <קישור לפוסט, אם יש>
תאריך פרסום: YYYY-MM-DD
הערות: <כל מה שכתוב בפוסט ולא מופיע בצילום – LTV, מטרה, שלב>
```

אחר כך מבקשים מ-Claude: "עבד את התיבה". הוא יחלץ את המסלולים, יוסיף רשומות ל-`public/data/records.json`,
יעביר את הצילום ל-`public/screenshots/` (אחרי הסתרת שמות ופרטים מזהים) וירוץ `npm test` כדי לוודא שכל הרשומות תקינות.
