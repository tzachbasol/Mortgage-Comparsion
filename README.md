# מתכנן תמהיל משכנתא

אתר לבניית תמהילי משכנתא, שבו כל ריבית מבוססת על **רשומות ממקור אנושי**: פוסטים ותגובות בקבוצות התייעצות,
פורומים, או הצעות שקיבלתם בעצמכם. לכל מסלול בתמהיל אפשר לפתוח את רשימת הרשומות שעליהן הריבית מבוססת,
עם תאריך, קבוצה, בנק, שלב ההצעה, ציטוט וצילום מסך.

## לשוניות

| לשונית | מה יש בה |
|---|---|
| **בניית תמהיל** | מוסיפים מסלולים (סוג, תקופה, סכום, תדירות שינוי). הריבית היא חציון הרשומות התואמות, ואפשר לדרוס אותה ידנית. "על אילו שליפות זה מבוסס?" מציג את המקורות. |
| **השוואה למשכנתא שלי** | מזינים את יתרות המשכנתא הנוכחית ועלויות המיחזור, ומשווים אותן לתמהיל שנבנה: החזר חודשי, סך התשלומים, חיסכון ונקודת איזון. |
| **מאגר הרשומות** | צפייה בכל הרשומות, הוספת רשומה מפוסט או צילום, וייבוא וייצוא JSON. |
| **מקורות ומתודולוגיה** | איך מחושבת כל ריבית ומה המגבלות. |

## מבנה הנתונים

- `public/data/records.json`: המאגר הרשמי, שנשמר בריפו. מתחיל ריק. **כל הרשומות כאן חייבות להיות אמיתיות.**
- `public/data/demo-records.json`: 3 רשומות מומצאות לבדיקת הממשק. הן כבויות כברירת מחדל ומסומנות בוורוד בכל מקום.
- רשומות שמוסיפים דרך האתר נשמרות ב־localStorage. כדי לשתף אותן: "ייצוא", ואז מיזוג ל־`records.json`.

כל רשומה חייבת: סוג מקור, שם קבוצה או פורום, תאריך פרסום, ולפחות אחד מאלה: קישור, צילום או ציטוט
(נבדק ב־`src/lib/validate.ts`, והטסטים נכשלים אם רשומה בריפו לא עומדת בזה). בפריים נשמר **המרווח** מהפריים.

```jsonc
{
  "id": "fb-2026-09-001",
  "source": {
    "kind": "facebook_post",           // facebook_post | facebook_comment | forum_post | whatsapp | personal_offer | other
    "channel": "משכנתאות – התייעצויות",
    "url": "https://facebook.com/groups/…/posts/…",
    "postedAt": "2026-09-20",
    "authorLabel": "חברת קבוצה",        // בלי שמות מלאים
    "screenshot": "screenshots/fb-2026-09-001.png",
    "quote": "קיבלנו מלאומי: פריים 30 שנה P-0.6, קל\"צ 20 שנה 4.75…",
    "collectedAt": "2026-09-26"
  },
  "bank": "לאומי",
  "stage": "initial",                  // initial | negotiated | approved | signed | unknown
  "loanAmount": 1200000,
  "tracks": [
    { "type": "prime", "termYears": 30, "primeMargin": -0.6 },
    { "type": "fixed_unlinked", "termYears": 20, "rate": 4.75 },
    { "type": "variable_linked", "termYears": 25, "rate": 3.5, "changeEveryYears": 5 }
  ]
}
```

## הרצה

```bash
npm install
npm run dev      # פיתוח
npm test         # חישובים, התאמת רשומות, ותקינות records.json
npm run build
```

האתר עולה אוטומטית ל־GitHub Pages בכל push ל־`main` (`.github/workflows/deploy.yml`).
יש להפעיל Pages בהגדרות הריפו: Settings → Pages → Source: GitHub Actions.

## הנחות החישוב

- לוח סילוקין שפיצר. במסלולים צמודים הקרן מוצמדת למדד כל חודש, לפי האינפלציה שהוזנה, וההחזר מחושב מחדש.
- הריבית נשארת קבועה לאורך כל התקופה, גם בפריים ובמשתנות.
- ריבית הפריים מוזנת ידנית, ויש לוודא אותה מול בנק ישראל.
- האתר אינו ייעוץ משכנתאות.
